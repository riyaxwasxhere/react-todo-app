# ✅ React Todo App

A simple and responsive Todo application built while learning React. This project helped me understand React fundamentals such as components, state management, event handling, and local storage.

---

## ✨ Features

- ➕ Add tasks
- ✏️ Edit tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 💾 LocalStorage persistence
- 📱 Responsive design

---

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- CSS

---

## 🚀 Getting Started

```bash
git clone https://github.com/riyaxwasxhere/react-todo-app.git

cd react-todo-app
npm install
npm run dev
```
